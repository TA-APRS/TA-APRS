## Genel Bakış

**TA-APRS**, amatör telsizciler için geliştirilen Windows tabanlı APRS
Digipeater ve iGate yazılımıdır.

Amacı, Linux bilgisi gerektirmeden kolay kurulabilen ve yönetilebilen
modern bir APRS altyapısı sunmaktır.

## Proje Durumu

🚧 Aktif geliştirme aşamasında

Yazılım gerçek RF ortamında test edilmektedir. Henüz genel kullanıma
sunulmamıştır.

## Planlanan Özellikler

-   APRS Digipeater
-   APRS iGate
-   Fill-in Digipeater
-   WIDEn-N Digipeater
-   APRS-IS Bağlantısı
-   Ses Kartı AFSK Modemi
-   RTS/DTR PTT Kontrolü
-   DTMF Uzaktan Kontrol
-   Paket Analiz Motoru
-   Duplicate Paket Filtresi
-   Türkçe / İngilizce Arayüz
-   Windows Kurulum Paketi

## Geliştiriciler

-   **TA3JO** -- Abidin Çakır
