# TA-APRS

> **Notice**
>
> TA-APRS is currently under active development and on-air testing. The first public release will be announced after field testing has been completed.

## Overview

**TA-APRS** is a Windows-native APRS Digipeater and iGate platform designed for amateur radio operators.

The project aims to provide an easy-to-use APRS infrastructure solution without requiring Linux knowledge or complex command-line configuration.

TA-APRS started as a hobby project by amateur radio operators and is being developed as a non-commercial software project for the amateur radio community. The software is intended to be made available free of charge.

## Current Status

🚧 Development in progress

The software is currently under active development and real-world testing. It is **not yet publicly released**.

## Planned Features

- APRS Digipeater
- APRS iGate
- Fill-in Digipeater
- WIDEn-N Digipeater
- APRS-IS Connectivity
- Soundcard AFSK Modem
- RTS/DTR PTT Control
- DTMF Remote Control
- Packet Analysis Engine
- Duplicate Packet Filtering
- Turkish / English Interface
- Windows Installer
